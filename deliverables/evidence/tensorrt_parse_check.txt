## PipeGen compile attempt 1 (2026-10-17T18:49Z): "ONNX parse failed: Failed to import initializer"
Cause reproduced in the PipeGen container with scripts/trt_parse_modes.py (TensorRT 10.3.0):
  parse(bytes) cwd=/opt/PipeGen       -> ok=False, "WeightsContext.cpp:178: Failed to open file: vggt.onnx.data"
  parse(bytes, path) cwd=/opt/PipeGen -> ok=True, 18751 layers
  parse(bytes) cwd=model dir          -> ok=True, 18751 layers
PipeGen parses the model bytes without the file path while its working directory is /opt/PipeGen,
so external weights (required for models > 2 GB) are looked up in the wrong directory.
Workaround (no model change): symlink /opt/PipeGen/vggt.onnx.data -> /home/atharv/spectra/repo/models/vggt-onnx/vggt.onnx.data
After the link: parse(bytes) cwd=/opt/PipeGen -> ok=True, 18751 layers.
The compile record also showed "precision": "fp32", "fp16": false although FP16 was selected.
